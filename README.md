# ShopLite — Full-Stack E-Commerce Application

A full-stack e-commerce web application built as a practical learning and portfolio project.

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Pydantic

### Frontend
- React
- JavaScript
- HTML
- CSS
- Axios

### Tools
- Git & GitHub
- Pytest
- Docker

## Planned Features

- User registration and login
- JWT authentication
- Product catalog
- Product search and filtering
- Shopping cart
- Checkout and orders
- Order history
- Admin dashboard
- Product and inventory management

## Project Status

Currently under development 🚧

## Learning Goals

Building this project to practice backend development, REST APIs, databases, authentication, frontend integration, testing, and deployment.
